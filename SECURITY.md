# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately, either through GitHub's
"Report a vulnerability" button on the Security tab of this repository,
or by email to insights@qx.plus.

Include the affected version, steps to reproduce, and the impact you expect.
We aim to acknowledge reports within a few working days.

## Supported versions

Only the latest released version of the extension receives security fixes.
